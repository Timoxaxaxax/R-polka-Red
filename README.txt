ПЛАН ПОЛКИ — PWA
Открой index.html через HTTPS-хостинг (например GitHub Pages, Netlify или Vercel).
На iPhone открой адрес в Safari → Поделиться → На экран Домой → Открыть как веб-приложение → Добавить.
Магазины и история хранятся локально на iPhone. Для синхронизации между устройствами понадобится сервер/аккаунт.
